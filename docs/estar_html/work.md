# 作品情報

## URLとID

作品URLは`https://estar.jp/novels/{workId}`。実例は`/novels/594`と`/novels/26544596`。作品IDは数字だけの単一要素。複合IDではないため区切り文字は不要。

## NovelInfo対応

`workId`は文字列化した数値。`title`、著者、あらすじ、`genreId`、タグ、文字数、更新日時、完結状態をSSR状態またはDOMから取得可能。`NovelSite.metaText`はスター数の実フィールドを1作品で追加確認してから決める。未確認値を表示用に推測しない。
