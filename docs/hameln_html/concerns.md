# 実装上の懸念

## 結論

|論点|結論|
|---|---|
|作品ID|実測した作品URLは `/novel/{10進数字}/`。複合要素ではなく、`workId`単一文字列で表現可能|
|100話超目次|対象は68話が1ページ。100話超のページングは未確認。全件取得の現実的リクエスト数は未確定|
|ルビ|取得サンプルにルビなし。`NovelContentElement` / `tategaki`対応可否は未確定|
|CSRF/Cookie|本文はHTML直埋め込み。本文取得にCSRF POSTは不要。Cloudflare Cookieは発行されるため、常時不要とは断定しない|
|規約|規約本文は未取得。適法性・利用条件は判定不能|
|R18|R18本文は未取得。判別レスポンスも未確認|

## 取得制限

robots.txtの`User-agent: *`は、特定の`?mode=`操作と`/conv/pdf/`を禁止している。作品、目次、本文、通常検索、ランキングは`*`向けのDisallowとしては記載されていない。ただしGPTBot等には`Disallow: /`がある。Novelty専用UAの扱い、レート制限の明示は未確認。最低1秒間隔、キャッシュ優先が必要。

## DOMの不安定性

短編は作品URLが本文へ遷移し、連載は目次を返す。作品情報DOMも連載目次と短編本文で異なる。`span[style]`や`align`依存を避け、`#maind`、`#honbun`、`episode-list__*`を優先する。ただし短編固有の作品情報セレクタは追加実測が必要。

## 未完了調査

利用規約、通常検索結果、ランキング、100話超作品、作品情報ページ、削除・非公開・R18のHTTP応答、ルビ・挿絵・傍点・改ページの実例はCloudflareチャレンジまたは安全上の制約で未確認。これらが埋まるまで本実装の仕様確定・マスタデータ確定は不可。
