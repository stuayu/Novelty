# カテゴリ・ジャンル

ハーメルンの取得済みHTMLでは、作品ページの `itemprop="genre"` は「原作：」を表し、リンク先は検索URLだった。トップページの「原作カテゴリ」も固定ID付きマスタではなく、`word=原作：...` の検索リンクだった。

## 確認できたカテゴリ

トップページで確認できた原作カテゴリは、以下のように検索語として表現される。

|分類|実値|
|---|---|
|汎用|その他原作、二次創作、オリジナル|
|原作例|ARMORED CORE、BanG Dream!、BLEACH、FAIRY TAIL、Fate/、GOD EATER、HUNTER×HUNTER、Infinite Dendrogram、Limbus Company、Muv-Luv、NARUTO、NEW GAME!、ONE PIECE、Re:ゼロから始める異世界生活、VOICEROID、アークナイツ、アイドルマスター、アカメが斬る!、アクタージュ、アサルトリリィ、アズールレーン、ありふれた職業で世界最強、暗殺教室、痛いのは嫌なので防御力に極振りしたいと思います。、イナズマイレブン、インフィニット・ストラトス、ウルトラマン、ウマ娘プリティーダービー、英雄伝説、オーバーロード、推しの子、オルクセン王国史、ガールズ＆パンツァー、学戦都市アスタリスク、かぐや様は告らせたい、陰の実力者になりたくて！、がっこうぐらし！|

トップページにはさらに多数の原作カテゴリがあるが、これはサイト全体の固定ジャンル一覧ではなく、表示時点の主要原作リスト。完全一覧・安定したIDは未確認。

作品HTMLで確認した「舞台：ファンタジー」「舞台：現代」「ジャンル：冒険・バトル」「ジャンル：恋愛」「ジャンル：ノンジャンル」は、検索URLに埋め込まれた語であり、サイト固有の数値IDではない。

## `GenreMaster`への結論

二階層のジャンルID体系は未確認。`bigGenreId` / `isBigGenre` に対応する確定マスタを作れない。原作カテゴリ・舞台・ジャンル・タグを別概念として扱い、動的な検索語を固定 `GenreMaster` に変換しない方針が安全。

## 追加確認済み（2026-08-25）

検索フォームの`gensaku`は、`その他原作`、`原作：二次創作`、`原作：オリジナル`と、表示時点の主要原作名を`option value`と表示名の文字列で列挙する。数値ID・安定したサイト内ジャンルIDはない。作品ページの`itemprop="genre"`も検索語リンクだった。

|id|name|bigGenreId|isBigGenre|
|---|---|---|---|
|なし|その他原作、二次創作、オリジナル、各原作名|なし|false|
|なし|舞台：ファンタジー等|なし|false|
|なし|ジャンル：冒険・バトル等|なし|false|

固定IDによる二階層マスタが存在しないことは確認済み。検索語の意味上の分類（原作・舞台・ジャンル）の内部階層は未確認。よって`GenreMaster`全件を確定生成することは不適合で、検索語をサイト固有データとして別扱いする。
