# ノベルアップ＋利用規約レビュー

- 調査日: 2026-08-25
- URL: https://novelup.plus/etc/tos
- 方法: ログインなし、curlのみ
- 条文引用は取得HTMLの原文。主語が運営者の条項と、ユーザー禁止を分離して判定

## robots.txt

https://novelup.plus/robots.txtはHTTP 200、text/plain。全文は test/fixtures/novelup/robots.txt。User-Agent:*の禁止は/my/、/edit/、/api/、/shop/point/。本調査は公開作品、本文、検索、ランキング、/etc/tos、/loginだけ取得。/api/、/my/等は取得していない。

|対象|判定|理由|
|---|---|---|
|公開作品・本文・検索・ランキング|適合|User-Agent:*の禁止パス外|
|/api/、/my/、/edit/、/shop/point/|不適合|robots.txtでDisallow|
|調査User-Agent|要注意|GPTBot等の明示禁止User-Agentは使用せず指定Chrome互換UAを使用|

## 条項レビュー

|条項|原文（抜粋）|判定|評価|
|---|---|---|---|
|第1条1〜3項|「サービス及び機能、コンテンツを利用する一切の行為に適用」「ユーザーはサービスを利用することにより…同意」|要注意|公開HTML取得・クライアント実装も利用行為に含まれ得るため、方針承認が必要|
|第6条3項|「機能等に、ユーザーもしくは…利用者の年齢による制限を設けることがあります」|要注意|年齢制限の回避禁止へ接続する。年齢制限本文は取得しない|
|第11条1〜2項|「必要なあらゆる機器、ソフトウェア、通信手段を…整備」「セキュリティ対策」|適合|一般的な利用環境の規定。自動取得許可ではない|
|第12条1項|「ユーザー自身の責任において本サービスを利用」|要注意|非公式クライアントのリスクを利用者側に置く一般条項|
|第13条1号|「著作権、商標権等の知的財産権を侵害する行為、又は侵害する恐れのある行為」|要注意|本文のローカル保存・再配布は権利侵害の検討が必要|
|第13条18号|「年齢による機能やツールの制限を逸脱して本サービスを利用する行為」|不適合|年齢制限を回避する実装は禁止対象|
|第13条20号|「設備に蓄積された情報を不正に書き換え、又は消去する行為」|適合|読み取り調査は該当しない|
|第13条21号|「ウィルス等の有害な…プログラム等を送信又は掲載」|適合|Noveltyは該当処理をしない|

|第13条24号|「法令、公序良俗又は本利用規約…に違反し、又は他者の権利を侵害すると…判断する行為」|要注意|包括条項。非公式クライアントと保存機能は所有者判断が必要|

|第18条3項|「投稿されるテキスト等の情報を監視したり、保存する義務を負いません」|適合|運営者の義務否定。ユーザーによるローカル保存許可ではない|
|第19条1〜3項|「情報の全部もしくは一部を削除し、公開範囲を変更し、又は閲覧できない状態」|要注意|非公開化後の取得を許可する条項ではない|

## 複製・転載・ローカル保存・非公式アプリ

取得規約本文に、利用者が公開本文を複製・転載・ローカル保存してよいという許諾は確認できない。第13条1号・22号・24号から、本文の恒久保存やオフライン提供は適合と判定できず、要注意。非公式クライアントアプリを名指しで許可・禁止する条項は未確認。ただし第1条、第12条、第13条22号・24号が適用されるため、無条件に適合とは言えない。

## 結論

公開HTMLを低頻度で読む調査はrobots.txtの許可パス内で実施した。一方、Noveltyの本文キャッシュ・オフライン読書は、規約上の明示許諾を確認できず、現段階では要注意。年齢制限回避、/api/・/my/等のrobots禁止パス利用、サーバー負荷を伴う取得は不適合。実装・配布判断はプロジェクトオーナーが行う。
