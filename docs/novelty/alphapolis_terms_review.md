# アルファポリス利用規約レビュー

- 確認日: 2026-08-24
- 対象: [アルファポリス利用規約](https://www.alphapolis.co.jp/pages/terms_of_service)
- 関連: アルファポリス対応 Phase 1

## URLの特定

作品ページのフッターに `https://www.alphapolis.co.jp/pages/terms_of_service` の「利用規約」リンクがあった。`/terms` と `/help/terms` は404。対象URLはサーバサイドHTMLで本文を取得できた。

## 条項レビュー

| 条項 | 原文の要点 | 判定 |
|---|---|---|
| 2.3 | 「利用者」は会員登録の有無にかかわらず本サービスを利用するすべての方 | 要注意。非ログインのNovelty利用者も規約対象 |
| 2.4 | コンテンツは小説・漫画等とサービス内の一切のテキスト・画像 | 要注意。本文HTMLと画像も対象 |
| 7.1 | コンテンツ閲覧以外のサービスには会員登録が必要 | 適合。初期調査・公開閲覧は会員機能を使わない |
| 10.1 | コンテンツは当社指定設備へ接続し、当社の定める範囲内でのみ使用可能 | 要注意。非公式クライアントの範囲が明記されていない |
| 10.2 | コンテンツの権利は当社または投稿会員に帰属し、知財の使用許諾をしない | 要注意。公開HTMLの解析だけで権利許諾にはならない |
| 10.3 | 「いかなる方法によっても複製、送信、譲渡、貸与、翻訳、翻案その他の利用」を禁止 | **不適合**。Noveltyの本文ローカル保存・オフライン読書は複製に該当し得る |
| 10.4 | コンテンツの再使用許諾を禁止 | 適合。第三者への再配布・再許諾は行わない前提 |
| 13［4］ | 有害なプログラム・スクリプト等のアップロードを禁止 | 適合。取得のみでアップロードしない |
| 13［5］ | 第三者の知的財産権侵害を禁止。二次創作投稿も禁止 | 要注意。取得対象の著作権は利用者側にない |
| 13［8］ | 許諾のない営業・宣伝・広告・勧誘・営利目的行為を禁止 | 要注意。Noveltyを非営利・広告なしに限定しても、10.3の複製禁止は残る |
| 13［11］ | 他人の個人情報・登録情報の不正収集・開示・提供を禁止 | 適合。著者公開名・公開URL以外の登録情報を収集しない |
| 13［16］ | 管理運営を妨げる等、当社が不適切と判断する行為を禁止 | 要注意。レート制限とrobots.txt遵守が必要 |

## 自動アクセス・スクレイピング

規約本文を `crawler`, `scrape`, `robot`, `bot`, `自動アクセス`, `スクレイピング` で確認した範囲では、明示的なクローラー禁止条項は未確認。これは許可ではない。第10.1、10.3、13［16］の一般条項があるため、robots.txt遵守だけで適合とは判定しない。

## 非公式クライアント

非公式クライアントアプリを名指しした条項は未確認。第10.1の「当社の指定する設備」および第10.3の複製禁止との関係は要注意。

## アクセス方針の評価

| 方針 | 判定 |
|---|---|
| robots.txt遵守 | 適合。対象URLは `User-agent: *` の禁止対象外 |
| 1秒以上の間隔 | 要注意。技術的には適合方向だが、規約の複製禁止は解消しない |
| 公開HTMLの取得・解析 | 要注意。明示禁止は未確認だが、規約10.1/10.3との関係が未許諾 |
| ローカル保存・オフライン読書 | **不適合**。第10.3の複製禁止と衝突 |

## 結論とflag

**実装着手前にflagする。** 既存計画の作品取得・目次・本文取得だけでなく、特にオフラインダウンロードが第10.3項に抵触する可能性が高い。アルファポリス運営への許諾確認、またはオフライン保存を除外したスコープ変更が必要。規約確認だけで実装開始してはならない。
