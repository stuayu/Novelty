# 実装上の懸念事項

## 結論

公開作品の読書コアは実装着手可能。取得手段は埋め込みJSON-LDとHTML DOM。公式APIは未確認。内部APIはrobots.txtのDisallow: /api/により調査・実装候補から除外。本文は公開HTMLのGETに直接埋め込まれ、CSRFトークン・Cookie不要。

| 論点 | 結論 |
|---|---|
| 使える取得手段 | JSON-LD補助 + HTML DOM。APIは未確認、/api/はrobots禁止 |
| 作品ID | /story/{数値}の単一要素 |
| 100話超目次 | 372話で30話/ページ、?p=1..4。全件取得は4リクエストの実例 |
| ルビ | 標準ruby/rb/rt/rpを確認。NovelContentElement.rubyTextへ変換可能 |
| tategaki | 実HTMLからの要素変換は可能。ただし縦書き表示統合は未検証 |
| 本文のCSRF/Cookie | 公開GET本文に不要 |
| 規約 | 第13条22号のサーバー負荷禁止等により、レート制限必須 |

## 取得できない作品

存在しない作品 /story/999999999はHTTP 404で「ページが見つかりません」「移動もしくは削除された可能性があります」。削除済みをHTTPステータスだけで判別できる実例としては404だが、非公開・年齢制限・有料作品の状態別レスポンスは未確認。HTTPステータスだけで全条件を判別できるとは結論しない。年齢制限作品の本文は採取していない。

## アカウント

ログイン画面だけ観察。POST /login、hidden _token、mail、password、任意のremember=1。GET時にXSRF-TOKENとhttponlyの_s Cookieが発行される。ログイン、登録、会員限定エンドポイントの実行はしていない。画面上はブックマーク、しおり、作者フォロー、レビューが会員機能。/my/は禁止のため実エンドポイントへアクセスしていない。
