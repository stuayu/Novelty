# 実装上の懸念事項

## 規約

`docs/novelty/alphapolis_terms_review.md` のとおり、実装着手前に不適合フラグ。第10.3項が配信コンテンツの複製を方法を問わず禁止するため、既存計画の「オフラインダウンロード」と両立しない。

## 多話数作品

目次は作品ページ1レスポンスの `chapterEpisodes` に含まれる実例を確認。100話以上でのページングは未確認。したがって「現実的なリクエスト数で全件取得可能」とはまだ結論できない。実装前に100話以上の実作品を1件、robots.txtとレート制限下で確認する必要がある。ページングがなければ目次取得は1リクエスト、本文は話数分の追加取得となる。

## ルビ・縦書き

採取本文に `<ruby>`、記法ルビ、独自ルビクラスは出現しなかった。ルビ対応可否は未確認。`NovelContentElement` と `packages/tategaki` が正しく扱えるという結論は禁止。ルビを含む実本文fixtureを追加採取してから、専用マッピングと縦書き表示を検証する。

## ログインなしで読めない作品

作品詳細JSONに `isRental`, `rentalBookId`, `isPublic`, `isPreview`, `rentalConfirm`、本文ページの `rentalConfirm` が存在する。実例では無料本文をログインなしで取得できた。有料・レンタル・R18で本文取得が拒否される条件と返却HTMLは未確認。`isRental`、`rentalBookId`、`isPublic`、`isPreview`、本文POSTのHTTPステータスとレスポンス内容を判定材料にするが、実装仕様としては未確定。

## 本文取得

本文はGET HTMLに埋め込まれず、ページ内JavaScriptがCSRFヘッダーとtokenを使ってPOST取得する。tokenは固定値ではない。Cookie、CSRF、tokenの扱いを実装前に再確認する必要がある。

## TLS

調査環境ではCA検証が失敗したため採取時だけcurl `-k` を使用。アプリ実装で証明書検証を無効化してはならない。

## 確認済み

- 対象小説URLはrobots.txt許可。リクエスト間隔1秒以上必須
- 本文POSTはCSRF、Referer、XHR、Cookieを伴う
- 341話作品で目次ページングなし
- ルビは`<ruby><rt>`。本文fixtureあり
- 無料本文・R18公開本文は非ログインで200
- 非公開レンタル話はGET 403。エラーHTMLは「この話はレンタル中ではありません。レンタルする場合は目次に戻ってレンタルしたい話を選択してください。」

## 未確認

`isRental`、`rentalBookId`、`isPublic`、`isPreview`、`rentalConfirm`の全組合せ、ログイン後のレンタル挙動、R18非公開話、通常の非公開作品、傍点・画像・改ページ専用HTML、本文での`|漢字《よみ》`、検索高度条件の完全なGET仕様、複数カテゴリのOR/AND。

未確認項目は推測で実装しない。
